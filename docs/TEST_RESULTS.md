## 1.7.0／文化史の大きな時代区分

文化史の通常の選択画面を、地域6区分と地域ごとの大きな時代区分に整理した。ヨーロッパは古代／中世／ルネサンス・宗教改革／17〜18世紀／19世紀／20世紀以降の6個。細かな教材タグと分野一覧は任意で開く。ID・DB・年号UIは変更していない。別途追加された教材の名称衝突で同期が拒否される問題を検出し、is-papermakingの名称のみ地域を明記して修正した。問題文とカードIDは保持している。

`npm ci` 成功。`npm test` は8ファイル83件成功、`npm run build` 成功、`npm run test:e2e` は25件すべて成功（従来21件と新規4件）。同梱365項目と、別途公開された東洋文化史の追加分の大区分対応、時代をまたぐカードの重複防止、地域変更時の選択解除、難易度・分野・画像・復習モードとの組合せ、元の教材タグと誤答履歴の保持、360px・393pxでの操作を検証した。旧来の詳細な絞り込みは、詳細欄を開いたうえで従来のテストを維持している。同梱教材の回帰試験は固定した差分JSONを使い、随時増える公開教材の件数に依存させない。実際の公開差分の検証はscope.e2e.tsの別試験で行う。

画像：[文化史の時代選択](../artifacts/scope-mobile.png)。全世界一律の年号境界は使用せず、地域別の既存タグから暫定的に集約する。未提供の東洋文化史の分類精度とAndroid実機操作は未検証。

## 再現手順

```sh
npm ci
npm test
npm run build
npx playwright install chromium  # Chromiumが未導入の場合
npm run test:e2e
npm run sheets:seed
```

LinuxのシステムChromiumは自動検出します。それ以外の既存ブラウザを利用する場合は`CHROMIUM_PATH`を指定できます。Playwrightはlocalhostの4173番を使用します。スクリーンショットは[デスクトップ](../artifacts/desktop.png)、[スマートフォン](../artifacts/mobile.png)、[画像カード](../artifacts/study-mobile.png)に保存しています。
