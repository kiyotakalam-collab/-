# 検証結果

## 1.2.0／教材v3の変更

2026年11月9日に提供された東進『スタンダード世界史探究』の写真5枚を目視で読み、35知識項目・45カードを追加した。計53項目・70カード。教材本文や写真はアプリに含めず、出典はURLなしの提供写真として記録した。新規項目の事実・難易度は暫定扱い。既存の知識・カードIDは変えていない。

## 1.1.0／教材v2の変更

Lv.1〜3を短い一問一答に改訂し、既存24カードのID・解答を維持したまま『国家』→プラトンのカードを追加しました。レベル選択を大きな選択カードに変更し、累積／単独それぞれの出題範囲を具体的に表示します。

単体・統合試験は6ファイル47件、本番ビルド後のChromiumブラウザ試験は14件すべて成功。旧教材v1での誤答を、教材v2への更新後も保持し、更新後に正答しても累積誤答が減らないことを確認しています。公開後に独自のSheetsマスターを使う端末では、同梱教材で独自マスターを上書きしません。

レベル選択は360px・393px・1440pxで横はみ出しなし、押せる領域48px以上を確認。累積／単独の抽出・他の条件を変えた際の選択保持・キーボードの矢印移動とフォーカス保持も検証しました。[スマートフォンの選択画面](../artifacts/levels-mobile.png)と[デスクトップの選択画面](../artifacts/levels-desktop.png)を保存しています。

## 再現手順

```sh
npm ci
npm test
npm run build
npx playwright install chromium  # Chromiumが未導入の場合
npm run test:e2e
npm run sheets:seed
```

LinuxのシステムChromiumは自動検出します。それ以外の既存ブラウザを利用する場合は`CHROMIUM_PATH`を指定できます。Playwrightはlocalhostの4173番を使用します。スクリーンショットは[デスクトップ](../artifacts/desktop.png)、[スマートフォン](../artifacts/mobile.png)、[画像カード](../artifacts/study-mobile.png)に保存しています。
