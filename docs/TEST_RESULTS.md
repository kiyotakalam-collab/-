## 再現手順

```sh
npm ci
npm test
npm run build
npx playwright install chromium  # Chromiumが未導入の場合
npm run test:e2e
npm run sheets:seed
```

LinuxのシステムChromiumは自動検出します。それ以外の既存ブラウザを利用する場合は`CHROMIUM_PATH`を指定できます。Playwrightはlocalhostの4173番を使用します。スクリーンショットは[デスクトップ](../artifacts/desktop.png)、[スマートフォン](../artifacts/mobile.png)、[画像カード](../artifacts/study-mobile.png)に保存しています。
