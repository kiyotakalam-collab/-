# 文化史の地域・時代選択

v1.7.0では、元の教材タグを表示用の大区分に集約する。教材の正式なregion/era、知識ID、カードID、行バージョン、回答履歴は変更しない。保存済みの独自教材にも同じ表示処理を適用する。

通常の地域選択はヨーロッパ／中国／イスラーム／インド／その他アジア／その他。ヨーロッパは既存教材のギリシア・東地中海・ローマ・西ヨーロッパ・イタリア・ヨーロッパ・アメリカなどを含む。既存の「世界各地」の探検はその他に分類する。

ヨーロッパの時代選択は次の6個と「全時代」。

- 古代
- 中世
- ルネサンス・宗教改革
- 17〜18世紀
- 19世紀
- 20世紀以降

「19世紀文学」「19世紀美術」などは同じ19世紀へまとめる。「18〜19世紀」「19〜20世紀」のような元のタグは両方の区分に含めるが、カード自体を複製しない。「科学技術の伝播」は中世とルネサンス、「科学革命」はルネサンスと17〜18世紀をまたぐテーマとして扱う。これは学習範囲を選ぶための暫定的な集約で、個別項目に新たな年代情報を付け加えるものではない。

中国・インド・その他アジアは古代・中世／近世／近現代、イスラームは成立期・中世／近世／近現代、その他は近代以前／近現代を用意する。教材の地域固有の時代名・王朝名から分類し、全地域に同一の西暦境界を適用しない。未登録の地域を選ぶと0件と開始できない理由を表示する。将来の未知のタグは「全時代」と「その他・時代確認中」から必ず参照できる。

複数の地域・時代を選択できる。地域の変更で不適合になった時代選択を解除し、元の細かなフィルターとの隠れた矛盾を避けるため、詳細な地域・テーマの指定をクリアする。「全時代」は詳細テーマの指定も解除する。難易度・分野・文字／画像・復習モードは従来どおり組み合わせる。

元の細かな地域・時代は、閉じた「細かいテーマで絞る（任意）」を開いたときだけ表示する。用語一覧や問題の出典では元の教材情報を維持する。文化史DB・年号DB、両方の公開教材JSONおよび年号UIはこの変更の対象外。
