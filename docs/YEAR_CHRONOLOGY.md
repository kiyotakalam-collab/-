# 年号エリア v1.9.0

年号ホームから「年代整序テスト」「インタラクティブ年表」に移動できます。下部の既存5メニューは維持しています。

## 年代整序

- 既存教材から、異なる4年・最大200年幅の近隣の出来事を組み合わせます。上下ボタンで並べ替え、答え合わせ後に正しい順序と登録年号を表示します。ドラッグ操作は実装せず、上下操作だけで完結します。
- Lv.1〜4・地域・時代、5／10／20問、全範囲／未学習／苦手優先。候補不足時は存在する問題数に減らし、比較可能な4件がなければ開始を無効にします。同一セットを同一セッションに重複出題しません。
- 4件の固定IDの集合を問題キーに使用。各回答の選択順序・正しい順序・正誤・日時・セッションを専用履歴に保存します。未学習・苦手も整序専用の履歴を参照します。直近5回答と累積正誤を表示し、正解しても誤答は減りません。

## インタラクティブ年表

- 同じ横方向の時間軸に地域別レーンを配置。地域名は教材から取得し、複数選択できます。開始・終了年、レベル、時代、縮小／標準／拡大を変更できます。
- 同年の出来事を含む全対象を別の段に配置し、カードの重なりを防ぎます。年表内だけを横スクロールでき、年代順の一覧も利用できます。
- タップした出来事の登録済み年号・地域・時代・レベル・解説・出典を表示します。解説や出典を生成して補いません。閲覧は成績に影響しません。
- 整数年・明示的な紀元前表記を数値で比較します。0年、期間、世紀、推定年代などは出題・年表配置から除外し、対象外件数を表示します。元の文字列は変更しません。

## 保存と互換性

年号DB `world-history-year-test` はv1→v2。既存 `meta`・`reviews` を保持して `orderingReviews` のみ追加します。整序の重複保存防止と履歴競合検出はDBでも行います。採点日時は単調増加で保存します。

年号バックアップはschema2で整序履歴も含みます。旧schema1を受け入れ、復元は履歴IDで追加統合します。IDの内容競合では教材・通常履歴・整序履歴の全復元を取り消します。旧バックアップの復元でも新しい整序履歴は消えません。

年号教材460件、`public/year-events.json`、文化史教材・機能・DBは変更しません。追加ライブラリはありません。共通main.tsの変更は年号ページ型と新規年号画面の再読み込み経路のみです。

## 検証と制限

単体テスト132件、ビルド、Playwright全39件が成功しました。旧DBで3誤答・2正答→移行→整序採点→再読み込み→教材同期→バックアップ→別DB復元・再復元で元の5IDと正誤数を保持することを確認しています。文化史の教材・履歴が不変であること、同年表示、複数地域・範囲・時代・難易度、360／393px、カード非重複、0件・対象不足、オフライン起動を検証しました。最終の実行結果はPRのChecksに記録されます。

実Android端末での操作・保存容量は未検証です。既存の500KB超バンドル警告は継続します。
