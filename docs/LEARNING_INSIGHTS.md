# 復習カレンダー・定着度 v1.10.0

総合ホームの「復習カレンダー」「定着度ダッシュボード」から利用する。両画面は共通の学習管理に属し、文化史・年号の既存5項目メニューを変更しない。再読み込み・ブラウザバック・オフラインに対応する。

## 復習予定と実績

- 文化史は既存 `getProgress()` の `nextReviewAt`、年号は `yearProgress()` の `dueAt` を参照する。新しい復習間隔を計算・保存しない。
- 全てのカレンダー日付・時刻は `Asia/Tokyo`。月送りの日付演算も端末のタイムゾーンに依存しない。
- 「いま期限到来」は現在時刻以前の全予定。「うち期限超過」は日本時間で前日以前の予定。「今日の予定」は今日の全予定で、今日これから期限が来るものも含む。今日の期限到来と未到来の件数も別に表示する。
- 日付には文化史・年号・合計の現在の復習予定数を表示する。実績は回答イベントの日時から別集計し、日付選択後に部門別の実際の回答数を確認できる。予定は各問題の最新の1件で、過去の予定の履歴を再現するものではない。
- 未学習には復習予定を付けない。削除・出題停止の問題は学習対象から除外し、過去の実際の回答は保持する。
- 日付別・期限到来・期限超過の対象から、文化史と年号を別々に既存の演習・採点処理へ渡す。未来の日付も任意に先取りできる。実際に回答した場合だけ履歴が追加され、次の表示で予定を再計算する。

## 長期定着度と復習緊急度 v1.12.0

長期定着度は既存の回答イベントを時系列で再生し、回答直前の既存の復習期限・予定間隔と実際の回答日時を照合する。期限自体を変更しない。

- 未学習：回答なし。
- 定着初期：回答はあるが、1日以上の予定間隔を迎えた後の正答なし。
- 定着途中：そのような正答が1回以上。
- 安定：連続正答3回以上・直近3回正答。最後の誤答以後、異なる日本時間の日に期限到来後の正答が2回以上あり、そのうち1回は7日以上の予定間隔を迎えてからの正答。
- 判定不能・再判定待ち：間隔を照合できる履歴なし、または日時不整合。

期限超過だけでは定着度を下げない。短時間の連続正答だけでも安定としない。判定用の派生情報はDBへ回答イベントとして保存しない。曖昧用語の単独定着度はrecall、グループ識別定着度はidentify/compareだけを集計し、対象問題すべてが安定の場合だけ安定とする。

緊急度は別に、期限未到来／本日復習（今日これからの予定を含む）／期限超過（日本時間で前日以前）／直近誤答・短期再復習／復習期限なし、と表示する。直近誤答を優先表示するが予定日時は変更しない。「いま期限到来」の件数は実際の予定時刻と比較する。

年代整序は実際に回答した組合せだけを集計し、未出題の総問題数は推計しない。独立した復習期限の仕組みがないため、定着度は判定不能、緊急度は期限なし。年号一問一答の復習予定を流用しない。旧形式の年号→出来事や文化史の識別演習も通常カードの集計に混ぜず、履歴は保持する。

## 弱点分析

4エリアを分け、地域・時代・分野の明示的な対応表で集約する。対応表は画面内にも表示する。元のタグも問題一覧に表示し、不明は未分類。分野タグのない年号は名称から推測しない。新しい曖昧用語やグループは取得後に自動集計される。未知の分類名も未分類で集計し、元の値を確認できる。

登録問題数、学習済み、回答数、累積誤答、累積正答率、最新20回答の正答率と件数、定着度分布、期限到来、失点原因を表示。0回答は0%ではなく未回答。登録5問・学習済み5問・回答20回・直近10回答以上の全条件を満たす区分だけを順位判定対象とし、それ以外はデータ不足と明示する。

順位は直近誤答率60%、定着初期＋定着途中/判定不能の半数を学習済み数で割った値30%、累積誤答率10%。累積誤答の絶対数だけで順位を決めない。グラフ・分類を押すと対象問題を絞り込み、既存の採点機能で演習できる。

## 失点原因とバックアップ

誤答後の任意入力、または分析画面の過去の誤答からA知識不足／B混同／C文脈・年代判断／D設問処理／Eその他を記録する。未入力は原因未記録。自動推測せず、登録理由も実際の誤答へ変換しない。

各エリアの既存metaストアに `errorCause:<area>:<eventId>` として `{area,eventId,cause,updatedAt}` を追加する。元の回答イベントは書き換えない。原因を消した場合もcause:nullと更新日時を保存する。DBバージョン・ストア構成は変更しない。年代整序と年号は別のareaで管理する。

各専用JSONバックアップに省略可能なerrorCauses配列を追加する。旧形式では省略可能で、復元しても新しい注記を消さない。同じ注記は二重登録せず、新しいupdatedAtを採用し、同時刻・異なる内容は競合エラーで復元全体を取り消す。実際の誤答イベントへの参照のみ許可し、別エリアの原因は復元しない。既存の回答・累積誤答・固定ID・教材JSON・復習間隔は維持する。

実Android端末での操作・保存容量は未検証。既存の500KB超バンドル警告は継続する。
