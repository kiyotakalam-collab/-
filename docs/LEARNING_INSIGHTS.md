# 復習カレンダー・定着度 v1.10.0

総合ホームの「復習カレンダー」「定着度ダッシュボード」から利用する。両画面は共通の学習管理に属し、文化史・年号の既存5項目メニューを変更しない。再読み込み・ブラウザバック・オフラインに対応する。

## 復習予定と実績

- 文化史は既存 `getProgress()` の `nextReviewAt`、年号は `yearProgress()` の `dueAt` を参照する。新しい復習間隔を計算・保存しない。
- 全てのカレンダー日付・時刻は `Asia/Tokyo`。月送りの日付演算も端末のタイムゾーンに依存しない。
- 「いま期限到来」は現在時刻以前の全予定。「うち期限超過」は日本時間で前日以前の予定。「今日の予定」は今日の全予定で、今日これから期限が来るものも含む。今日の期限到来と未到来の件数も別に表示する。
- 日付には文化史・年号・合計の現在の復習予定数を表示する。実績は回答イベントの日時から別集計し、日付選択後に部門別の実際の回答数を確認できる。予定は各問題の最新の1件で、過去の予定の履歴を再現するものではない。
- 未学習には復習予定を付けない。削除・出題停止の問題は学習対象から除外し、過去の実際の回答は保持する。
- 日付別・期限到来・期限超過の対象から、文化史と年号を別々に既存の演習・採点処理へ渡す。未来の日付も任意に先取りできる。実際に回答した場合だけ履歴が追加され、次の表示で予定を再計算する。

## 定着度の分類（優先順）

1. **未学習**：該当問題の回答履歴がない。
2. **要復習**：復習期限到来、直近の回答が誤答、直近3回答で2回以上誤答、または最終回答から30日以上経過して連続正答が3回未満。
3. **安定**：上記に該当せず、連続正答3回以上、直近3回答が全て正答、最終回答から30日未満、復習期限が未来。
4. **定着途中**：その他の学習済み問題。

分類は表示時の目安であり、既存の復習予定や累積正誤を変更しない。直近の成績を回復すれば、昔の累積誤答が多くても安定に分類できる。基準は画面内でも確認可能。

文化史はカード単位、年号は出来事→年号の問題単位で別集計する。文化史は既存の大地域区分・難易度別、年号は登録地域・時代・難易度別に表示する。弱い範囲の並び順は `(要復習×2 + 未学習 + 定着途中×0.5) / (対象数×2)` の降順。各分類と範囲を組み合わせて対象問題を演習できる。割合は四捨五入、グラフの幅は丸め前の比率を使用する。

**年代整序は専用履歴の累積回答・正答・誤答だけを別欄に表示し、カレンダーと一問一答の定着度には含めない。** 旧形式の年号→出来事の履歴や文化史の識別演習も、一問一答の集計には混ぜない。履歴自体は既存バックアップに保持する。

## データ保護・検証

新機能は既存スナップショットから集計する。`cultural-history-master`、`world-history-year-test` のDBバージョン・ストア・バックアップ形式、教材JSON、固定IDは変更しない。ライブラリ追加なし。Googleカレンダー同期は行わない。

`npm test` 全145件、`npm run build`、`npm run test:e2e` 全44件が成功。追加テストは単体9件・ブラウザ4件。

日本時間の午前0時・月末・年末・閏月、端末設定がロサンゼルスの場合、既存計算との復習日時一致、期限超過、予定と実績の分離、定着度と弱い範囲、旧バックアップの復元、整序履歴保持を検証した。カレンダーから両部門を実際に採点し、別の問題の3誤答・2正答と元のイベントIDを保持、予定が新しい日付へ移動することを確認。閲覧・途中離脱では正誤記録が増えない。360／393px、オフライン再読み込み、URL復元・ブラウザバックも確認した。

実Android端末での操作・保存容量は未検証。既存の500KB超バンドル警告は継続する。
